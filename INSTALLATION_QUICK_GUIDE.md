# Quick Installation Reference Guide

## 📱 iPhone/iPad Users

### Using Safari
```
Share Button (⬆️) → Scroll Down → "Add to Home Screen" → Add
```

### Using Chrome
```
Share Button (⬆️) → Scroll Down → "Add to Home Screen" → Add
```

---

## 🤖 Android Users

### Using Chrome
```
Install Banner (appears automatically) → Install
OR
Menu (⋮) → "Add to Home screen" → Install
```

### Using Other Browsers
```
Browser Menu → "Add to Home screen" → Confirm
```

---

## 💻 Desktop Users

### Chrome/Edge
```
Address Bar Install Button (⊞) → Install
OR
Menu → "Install WellRead" → Install
```

### Firefox
```
Menu (≡) → "Install" → Follow Prompts
```

---

## 🎯 Key Points

- **iOS**: Both Safari and Chrome work, use Share button (location varies)
- **Android**: Chrome provides best experience with auto-prompts
- **Desktop**: Look for install button in address bar or browser menu
- **All Platforms**: App must be installed to access content

---

## ⚠️ Troubleshooting

**App not installing?**
- Refresh the page and try again
- Make sure you're using a supported browser
- On iOS: Use Safari or Chrome
- On Android: Chrome is recommended
- On Desktop: Chrome, Edge, or Firefox work best

**Already installed but still seeing install screen?**
- Close all browser tabs with WellRead
- Open the installed app from your home screen/desktop
- The app should load without the install prompt

**Desktop browsers showing install gate?**
- Look for install icon in address bar
- Check browser menu for "Install" options
- Use the automatic install prompt button when available

**Need help?**
- iOS users: Share button works in both Safari and Chrome
- Android users: Look for automatic install banners in Chrome
- Desktop users: Check address bar for install icon or browser menu
